# MEKIT iPhone 기술 프로토타입

MEKIT의 출시 플랫폼은 독립 iPhone 앱으로 확정했습니다. 현재는 EARTH 한 모델을 반대편 손목에 합성하는 기술 검증 단계입니다. [이슈 #2 반영과 출시 방향](../docs/iphone-release-direction-2026-10-11.md)을 참고하세요. 웹과 GitHub Pages는 기존 상태로 유지합니다. 제품 기준은 **001 EARTH · 49,000원 · 완성 디자인과 길이 선택**입니다.

## 시작

`MEKIT.xcodeproj`를 Xcode에서 열고 MEKIT 스킴을 선택하세요. 생성 원본은 `project.yml`이며 XcodeGen으로 다시 만들 수 있습니다.

```sh
xcodegen generate --spec ios/project.yml
swift test --package-path ios/Core
xcodebuild build -project ios/MEKIT.xcodeproj -scheme MEKIT \
  -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO
```

Metal 도구가 없다면 `xcodebuild -downloadComponent MetalToolchain`을 실행합니다. 실제 기기에는 서명이 필요합니다. 연결된 iPhone을 잠금 해제하고 신뢰·개발자 모드를 사용자가 설정한 뒤, Xcode의 Signing & Capabilities에서 본인 Team을 선택하고 실행하세요. 번들 ID 기본값은 `com.casewingit.mekit.prototype`입니다.

최소 배포 버전은 iOS 17, 화면은 세로, 카메라는 후면 광각입니다. 지원 기기를 실제로 검증했다는 의미는 아닙니다. 현재 결과는 [검증 기록](../docs/iphone-validation-2026-10-11.md)에 구분합니다.

## 구현 구조

- `Core`: 독립 좌표 변환·2D 손목 포즈 근사·추적 평활화·250ms 만료·보정 범위·길이 규칙.
- `CameraController`: AVFoundation 후면 카메라, 90도 회전된 픽셀, Vision 단일 손 포즈, 약 15Hz 분석, 프레임 폐기.
- `PrototypeModel`: 권한·카메라 중단·앱 비활성화·재개 상태. 이전 실행의 비동기 응답은 버립니다.
- `MetalBraceletView` / `BraceletMesh` / `BraceletShaders`: 투명 3D 합성, 절차적 올리브 코드·분산 비즈·작은 매듭·단일 실버 원통 잠금장치, 깊이만 쓰는 손목 근사 마스크.
- `TryOnView`: 촬영 가이드, 길이 선택, 위치·크기·기울기 보정과 초기화, 카메라와 분리한 모델 검토.

카메라와 분석 영상은 저장·전송하지 않으며 마이크 권한도 사용하지 않습니다. 쇼핑·결제·계정은 없습니다.

## 확인할 순서

1. 앱의 카메라 시작 버튼을 누르고 권한을 허용합니다. 권한 거절 시 안내와 설정 이동을 확인합니다.
2. 반대편 손의 손가락과 손목이 모두 보이도록 비춥니다. 두 손이 보이거나 주요 점의 신뢰도가 낮으면 팔찌를 숨깁니다.
3. 손목을 천천히 이동·회전합니다. 좌표 일치, 흔들림, 추적 복구와 지연을 실제 기기에서 확인합니다.
4. 위치·크기·기울기를 보정하고 초기화합니다. 초기화해도 선택 길이는 유지되어야 합니다.
5. 근사 가림을 켜고 끄며 뒤쪽 코드·비즈가 가려지는지 확인합니다. 옆면·급회전·손등/손바닥 전환에서도 확인합니다.
6. 앱 전환·화면 잠금·카메라 사용 중단 후 팔찌가 숨겨지고 복귀 시 새 프레임부터 재개되는지 확인합니다.

시뮬레이터는 카메라 추적을 제공하지 않습니다. **3D 모델 검토**는 정적인 화면 포즈이며 실제 손목 추적 결과가 아닙니다.

모델 검토에서는 가림이 기본으로 꺼져 있습니다. 보정 패널의 스위치로 근사 마스크를 비교할 수 있으며, 카메라 착용 확인을 시작하면 가림을 켭니다. 이는 실제 손목 없이 렌더러 출력을 확인하는 기능입니다.

## 정확도와 자산 한계

Vision의 손 랜드마크는 2D입니다. 손목 중심·폭·화면상의 회전만 근사하고, 깊이·손목 둘레·실제 길이를 복원하지 않습니다. 화면에서 cm는 사용자가 선택한 완성 길이입니다. 보정과 길이 변경은 상대 시각 크기를 조절하며 실제 조임·핏을 보장하지 않습니다. 이슈 #2에 따라 기본 20.0cm, 비교 후보 19.5·20.0·20.5cm를 제공합니다. 18cm 손목 기준의 검토 후보이며 판매 사이즈나 착용 여유는 아직 확정되지 않았습니다. 이전 15~21cm 데모 규칙은 iPhone 앱에서 사용하지 않습니다.

가림은 타원형 실린더의 깊이 마스크이며 실제 피부의 윤곽·세그멘테이션·센서 깊이가 아닙니다. 카메라 밖으로의 회전은 자동 복원하지 못하고 기울기는 수동 보정입니다. 큰 회전에서 위치·가림이 부자연스러울 수 있습니다. 후속 실기기 영상에 따라 렌더러·추적·가림 방법을 변경합니다.

이슈 #2의 제품·AR·포장 기준 원문과 MATERIAL WRAP 보드를 [참고 폴더](../docs/references/github-issue-2-2026-10-11.md)에 보존했습니다. 최우선 원본 EARTH 제품 디자인 보드·별도 제품/AR 파일·실제 제품 3D 자산은 아직 없습니다. 따라서 3D 모델은 **검증용 임시 모델**이며 원본 제품의 정확한 배열·비율·텍스처를 확인한 모델이 아닙니다. 실제 제품 모델과 텍스처 확보 후 교체해야 합니다. FIT STUDY를 제작 도면이나 정확한 자산으로 사용하지 않습니다. MATERIAL WRAP 이미지의 촘촘한 비즈·중복 잠금장치도 복사하지 않습니다. 단일 잠금장치는 외형 표현이며 실제 기계식 잠금 기능은 검증하지 않았습니다.

## UI 자동 검증

```sh
xcodebuild test -project ios/MEKIT.xcodeproj -scheme MEKIT \
  -destination 'platform=iOS Simulator,name=iPhone 18 Pro' \
  CODE_SIGNING_ALLOWED=NO
```

이는 시뮬레이터의 안내·길이·보정 UI 검증입니다. 실제 카메라·손 추적·자연스러운 착용·가림 정확도 시험을 대신하지 않습니다.
