# MEKIT 해외 방향과 Maedeup 무드보드

작성일: 2026-10-20. 사용자는 미국·유럽 중심 검토를 선택했다. 국가별 수요는 미검증이며 공통 영문 커뮤니케이션을 탐색하는 디자인 연구다. 사용자 요청에 따라 이미지 생성과 HTML 검토 공간, GitHub Pages 공개 배포를 진행한다.

## 2026-10-21 선택 업데이트

사용자가 INDIGO LINE을 선택했다. 이후 메인 샘플 방향은 INDIGO이며, 아래 BLACK KNOT 우선 추천은 선택 이전의 기록이다. 새 랜딩페이지는 INDIGO 보드의 제품·착용·매듭·직물 네 장면을 활용한다. Studio 역시 Indigo를 첫 화면으로 두되 기존 보드 ID·메모는 유지한다. [사업 실행·조달 자료](MEKIT-launch-kit-2026-10-21.md)를 별도 문서로 제공한다.

## 의견

전통매듭 요소에 찬성한다. 2mm 다이니마 사용 로프·작은 무광 블랙 금속·원석 제외라는 현재 기준을 유지하면서, 매듭을 실제 구조와 제작 이야기로 연결하면 기존 해양 로프 팔찌와 다른 출발점을 설명할 수 있다. 한국적 요소를 더한 것 자체가 해외 구매 수요의 증거는 아니다.

권고 순서: 착용 모습과 편의 → 정확한 소재 → Maedeup라는 기법과 제작자 → 제작 과정. 영문은 “Maedeup — Korean decorative knotting”으로 설명하고, 실제 재현한 매듭 이름과 제작자가 확인되면 구체화한다. 장인 협업·한국 제조·천연염색을 아직 이루어진 사실처럼 표시하지 않는다.

미국과 유럽을 동일한 취향·규정·배송 시장으로 묶지 않는다. 미국의 워크웨어 관심 고객과 유럽 내 미니멀 액세서리·현대 공예 관심 고객을 초기 모집 가설로 비교할 수 있으나 국가 전체의 선호를 단정하지 않는다. 미국과 유럽 내 첫 국가를 좁히고 목표 고객에게 실물과 배송 포함 가격, 납기, 사이즈 교환 조건을 함께 보여준다. 제품 가격만 환산해서 가격 경쟁력을 판단하지 않는다. 해외 운송·반품·결제 비용을 새 원가표에 넣고, 국가별 판매·표시 요건을 확인한다. 이번 작업은 국가별 법규·세금·수요 조사나 진출국 확정까지 수행한 것이 아니다.

## 비교 방향

| 보드 | 전통 요소의 해석 | 추천/주의 |
|---|---|---|
| BLACK KNOT | 도래매듭의 작은 연결 구조, 먹빛 목재·한지의 여백 | 첫 실물 추천. 검은 매듭의 식별성과 차별성 확인 |
| INDIGO LINE | 작은 연결 매듭, 쪽빛 직물과 데님 | 일상 스타일링 비교안. 실제 색상 수급·이염 확인. 천연염색 주장 아님 |
| RED THREAD | 연봉매듭의 응축된 입체감에서 영감을 받은 작은 적갈색 포인트 | 차별화 비교안. 장식이 커지지 않도록 비율 검토 |
| THE STUDIO | 앞선 보드를 크게 보여주는 편집형 갤러리 | UI도 이미지로 생성해 보존. 실제 동작은 HTML 구현 |

첫 샘플은 BLACK KNOT, 인지 가능한 브랜드 포인트 비교는 RED THREAD를 우선 추천한다. 색상이나 매듭 형태가 생산 사양으로 확정된 것은 아니다.

## 문화 근거와 표현 한계

국립민속박물관의 MAEDEUP 전시는 한국 장식 매듭과 이부자 작가의 작업을 소개한다. 국회도서관의 『Maedeup: Korean traditional decorative knotting』 소개에는 도래매듭(double connection knot), 연봉매듭(lotus bud knot) 등의 명칭이 나온다. 해당 자료는 문화적 명칭을 확인하는 근거로 사용했다. 전시 이미지와 도면을 다운로드하거나 제품 이미지로 복제하지 않았다.

- [국립민속박물관 MAEDEUP 전시](https://nfm.go.kr/user/bbs/english/17/469/bbsDataView/23987.do?bbsDataCategory=&column=&page=2&search=&searchEDate=&searchSDate=)
- [국회도서관 소장자료](https://dl.nanet.go.kr/detail/MONO2201705517)

생성된 매듭은 시각적 영감이며 전통 기법을 정확하게 복원했다는 증거가 아니다. 실제 2mm 로프에서 매듭 크기·마찰·풀림·가공성과 완제품 강도를 검증해야 한다. 금속의 모재와 코팅은 이미지로 식별하거나 확정할 수 없다. 생성된 잠금장치 외형 역시 구매 가능한 확정 부품이 아니다.

## 생성 기록

내장 image_gen 도구로 세 제품 보드를 각각 생성했다. 네 번째 갤러리 UI 이미지는 앞선 세 이미지를 참조해 생성했다. 네 이미지 모두 `public/studio/images/`에 원본 PNG로 보존하고, 실제 사용한 프롬프트는 `public/studio/prompts/`에 보존한다. CLI/API 대체 생성기를 사용하지 않았다.

시각 확인: 원석·우드 비즈 없음, 슬림 단일 로프, 작은 무광 검은 금속, 손목 스케일과 세 가지 색 방향을 확인했다. 보드 2의 도자기와 보드 1·3의 목재는 배경 재료다. 이미지의 수치 없는 외형만으로 2mm 실측을 인증하지 않는다.

## 확인 공간

공개 URL: https://casewingit.github.io/mekit/studio/

HTML/CSS/ES modules로 만든 독립 정적 페이지다. 네 보드의 이전·다음/썸네일/키보드 화살표/터치 스와이프, 확대 모달, 원본 다운로드, 보드별 검토 메모, Markdown 메모 내보내기를 제공한다. 직접 링크 예: `/studio/#red-thread`.

메모는 현재 브라우저 localStorage에만 저장되며 서버·GPT로 전송하거나 다른 기기로 동기화하지 않는다. 저장소가 차단되면 메모를 메모리에 유지하고 내보내기를 안내한다. 사용자에게 공개 페이지임을 알리고, 개인정보·내부 사업 보고서를 갤러리에 자동 게시하지 않는다.

배포는 `node scripts/deploy-studio.mjs`로 gh-pages의 `studio/`만 갱신한다. 그 외 기존 랜딩 파일은 전후 SHA-256 목록을 비교해 보존한다. 전체 웹을 추후 배포하면 Vite public 복사를 통해 동일 경로가 포함된다.

검증 명령: `node --test tests/studio.test.mjs`; 브라우저에서 데스크톱·모바일 화면, 탐색, 메모 유지, 확대/닫기, 직접 링크와 공개 배포 결과를 확인한다.
