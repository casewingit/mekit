# MEKIT iPhone 검증 기록

2026-10-11, Asia/Seoul. 개발 브랜치: `codex/iphone-earth-prototype`. 최신 사용자 요청은 **실물 제품 기준**이며, 현재 동작은 [실물 제품 정책](real-product-policy-2026-10-11.md)에 따른다.

## 현재 앱의 동작

EARTH 49,000원 예정 판매가와 19.5·20.0·20.5cm 미확정 실물 비교 후보를 표시한다. 후면 카메라 권한·Vision 손 포즈·2D 손목 위치와 방향 표시·추적 손실·카메라 중단·앱 이탈 처리를 제공한다. 손목 둘레나 착용감을 측정하지 않는다.

**실물에 근거하지 않은 임시 팔찌의 합성과 정적 모델 검토 진입을 제외했다.** 현재 제품용 3D 렌더러를 호출하지 않으며 위치·크기 보정 UI도 노출하지 않는다. 실물 사진·치수·부품 배열과 대조한 3D 자산을 확보한 뒤 제품 착용 표시·보정·가림을 연결해야 한다.

기존 Metal 메시·가림 코드는 과거 기술 검증 코드로 보존한다. 이 코드를 만든 사실이나 이전 GPU 테스트 성공은 실물 EARTH 제품의 외형·치수·질감·잠금 기능을 검증한 것이 아니다.

쇼핑·결제·계정·Android·고객 비즈 조립은 구현하지 않았다. 카메라 영상 저장·전송도 없다. 웹 소스와 Pages 게시 결과는 이번 수정에서 변경하지 않았다.

## 현재 자동 검증

새 회귀 테스트에서 기존 앱의 임시 모델 검토 버튼이 남아 있어 실패하는 것을 먼저 확인했다. 이후 해당 기능을 제외했다.

- 임시 모델 검토 진입과 “내 손목 위의 EARTH” 표시가 없고, 실물 기반 모델 미확보 안내가 카메라 시작 후에도 유지된다.
- 시뮬레이터에서 실제 iPhone 카메라가 필요하다는 안내와 카메라 중지가 동작한다.
- 세 가지 비교 후보 선택과 선택값 표시가 동작하며 판매 사이즈 미확정 안내가 유지된다.

이는 실제 손 추적·착용 영상·제품 외형이나 가림 정확도의 검증이 아니다. 현재 화면은 [실물 모델 미확보 안내](iphone-preview/physical-asset-required.png)로 보존했다.

```sh
xcodebuild build -project ios/MEKIT.xcodeproj -scheme MEKIT \
  -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO
xcodebuild test -project ios/MEKIT.xcodeproj -scheme MEKIT \
  -destination 'platform=iOS Simulator,name=iPhone 18 Pro' CODE_SIGNING_ALLOWED=NO
```

현재 로그: `/tmp/mekit-real-product-device.log`, `/tmp/mekit-real-product-final.log`. 결과 번들: `/tmp/mekit-real-product-final.xcresult`. 최초 회귀 실패 기록: `/tmp/mekit-real-product-red.log`. 임시 파일은 다른 컴퓨터로 자동 이전되지 않는다.

## 실물 자료와 iPhone 확보 후

실제 제작한 EARTH의 사진·치수·소재·부품 배열을 확보한다. 승인된 제품 모델을 실물과 대조한 뒤 앱에 연결한다. 임시 메시를 제품 자산으로 바꿔 표기하지 않는다. 원본 제품 디자인 보드도 참고 자료로 확보하되 실물 사진을 대신하지 않는다.

iPhone 신뢰·개발자 모드·Team과 서명은 사용자가 설정한다. 카메라 허용·거절·재허용, 좌우 이동·회전·조명·손 일부 가림·두 손·추적 손실과 복구, 앱 이탈·잠금·중단을 확인한다. 실제 기기·OS·지연·재현 조건을 기록한다. 실물 기반 팔찌의 부착·질감·가림 자연스러움과 허용 자세는 별도로 실제 영상에서 검증한다.

## 이전 렌더러 기술 실험 — 현재 제품 화면과 구분

로컬 커밋 `d7f422e`의 임시 형상은 이슈의 비율 목표를 참고한 절차적 메시였다. 당시 Swift 계산 테스트 13개, 시뮬레이터 UI·GPU 테스트 3개와 서명 없는 기기 빌드가 통과했다. GPU 검증은 깊이 마스크가 화면의 뒤쪽 기하를 제거하는지만 확인했다. 실물 제품·피부 윤곽·정확한 길이나 실제 카메라 추적을 확인한 것이 아니다.

과거 [임시 형상 화면](iphone-preview/history/model-review.png)과 [근사 마스크 화면](iphone-preview/history/approximate-mask.png)은 연구 이력으로 보존한다. 현재 UI나 실제 EARTH 제품 사진으로 사용하지 않는다. 현재 테스트에서 이 임시 모델 검토·GPU 화면 시나리오는 제외하고 실물 모델 미노출 회귀 검증으로 교체했다.
