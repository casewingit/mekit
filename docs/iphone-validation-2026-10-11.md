# MEKIT iPhone 프로토타입 검증 기록

기준일: 2026-10-11, Asia/Seoul. 개발 브랜치: `codex/iphone-earth-prototype`.

## 구현한 기능

`ios/MEKIT.xcodeproj` 및 재생성용 `ios/project.yml`을 추가했다. EARTH 한 모델, 49,000원 참고 표시, 완성 길이 선택, 후면 카메라 권한·프레임, Vision 손 포즈, 2D 손목 위치·폭·화면 회전 근사, 절차적 3D 팔찌 합성, 위치·크기·기울기 보정, 근사 깊이 마스크, 추적 손실 안내와 앱 수명주기 처리가 들어 있다.

쇼핑·결제·계정·Android·고객 비즈 조립은 구현하지 않았다. 카메라 영상 저장·전송도 없다. 공개 웹의 `src/`, `public/`, 빌드·배포 스크립트는 바꾸지 않았고 Pages를 재배포하지 않았다.

시뮬레이터의 모델 검토는 고정 화면 포즈다. 실제 손 추적 결과·실제 손목·센서 깊이로 표현하지 않는다. 현재 3D 모델은 검증용이며 원본 EARTH 보드의 배열·비율·텍스처를 확인한 제품 모델이 아니다.

## 자동 검증 내용

- 720×1280 프레임의 aspect-fill 크롭과 Vision Y축 반전, 다른 종횡비, 잘못된 치수.
- 횡단 방향을 화면 각도로 변환하고, 팔찌 중심을 손바닥 반대쪽에 배치하는 계산.
- 저신뢰/붕괴된 손 포즈 제거, 추적 중단·필터 초기화, 카메라가 멈출 때 250ms 만료. 실제 앱 이탈의 카메라 중지·재개는 실기기 시나리오에 남긴다.
- ±π 경계에서 각도 평활화가 반대 방향으로 크게 회전하지 않는지, 이전 시간의 프레임 무시.
- 보정 범위와 비정상 숫자 제거, 초기화, 15~21cm / 0.5cm 길이 선택.
- UI에서 시뮬레이터의 실제 카메라 필요 안내, 중지, 모델 검토 표시, 크기 보정 변경·초기화와 선택 길이 유지.
- GPU 출력의 팔찌 픽셀 수를 비교해 깊이 마스크가 뒤쪽 일부를 제거하면서 앞쪽은 남기는지 확인. 이는 기하학적 마스크의 출력 검증이며 실제 피부 가림의 정확도 검증이 아니다.

테스트는 초기 실패를 확인한 뒤 구현했다. 첫 UI 검증에서 제목 터치로 보정 패널이 열리지 않는 문제를 수정했다. 후속 재현에서 추적 대기 중 중지 제어와 모델 검토의 가림 스위치를 수정했다.

## 재현

```sh
swift test --package-path ios/Core
xcodegen generate --spec ios/project.yml
xcodebuild build -project ios/MEKIT.xcodeproj -scheme MEKIT \
  -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO
xcodebuild test -project ios/MEKIT.xcodeproj -scheme MEKIT \
  -destination 'platform=iOS Simulator,name=iPhone 18 Pro' CODE_SIGNING_ALLOWED=NO
```

이 Mac의 로그와 결과 번들은 `/tmp/mekit-swift-final.log`, `/tmp/mekit-ios-device-final.log`, `/tmp/mekit-ios-final.xcresult`에 있다. 임시 파일은 다른 컴퓨터로 자동 이전되지 않는다.

## 실기기에서 이어갈 항목

1. 누락된 원본 파일을 복사하고 기존 제품·AR·개발 문서 및 보드를 읽는다. 검증용 모델을 원본의 분산 비즈·슬림 올리브 코드 비율과 실제 3D 자산으로 갱신한다.
2. iPhone 신뢰·개발자 모드·Xcode Team과 서명을 사용자가 설정한다. 카메라 허용·거절·설정에서 재허용을 확인한다.
3. 손등·손바닥, 좌우 이동·회전, 두 손, 손목/손가락 일부 가림, 밝고 어두운 환경에서 좌표·지연·흔들림·추적 복구를 관찰한다.
4. 마스크 on/off, 수동 기울기, 크기·위치 보정, 앱 이탈·화면 잠금·카메라 중단을 비교한다. 손목에 자연스럽게 부착되는지 영상으로 판단한다.
5. 확인한 기기 모델·OS·프레임률/지연·문제 영상과 재현 조건을 기록한다. 필요하면 손목 세그멘테이션·깊이 추정·렌더러를 작은 검증으로 교체한다.

현재 방식은 2D 랜드마크와 타원형 마스크다. 실제 손목의 3D 형상·둘레·카메라 밖으로의 회전을 확보하지 못한다. 수동 보정과 화면의 길이는 정확한 조임·착용감을 보장하지 않는다.
