# MEKIT iPhone 출시 방향

2026-10-11 최신 사용자 요청: **MEKIT은 독립 iPhone 앱으로 출시한다. 웹은 랜딩 페이지로 유지한다.** 앱인토스와 네이티브 중 출시 플랫폼을 다시 선택하는 단계가 아니다. 현재 `ios/`는 출시 앱으로 발전시킬 기술 검증 프로젝트이며, App Store에 배포된 앱은 아니다.

브랜드·제품 기준은 [이슈 #2 수신 원문](references/github-issue-2-2026-10-11.md)을 참조한다. 첫 제품은 001 EARTH, 49,000원(VAT 포함). 고객은 완성 디자인과 길이를 선택한다. 고객에게 부품 조립이나 소재 구성을 요구하지 않는다. MEKIT 텍스트 브랜드와 “Make it your own”, Modern Craft 방향을 유지한다.

## 제품 기준과 자산 상태

- 딥 올리브의 얇은 코드, 여백 있는 우드·천연석 분산 배열, 작은 황동 스페이서는 실물 제품 개발 기준이다. 임의 형상을 실물 제품처럼 표시하지 않는다.
- 단일 브러시드 실버 원통 잠금장치와 작은 고정 매듭은 실물 사진·치수·부품 배열과 대조한 제품 모델로 구현해야 한다.
- 기본 비교 길이는 20.0cm. 18cm 손목을 기준으로 검토할 19.5·20.0·20.5cm 후보를 선택한다. 판매 길이 범위, 실제 내부 둘레, 착용 여유가 확정되었다는 뜻은 아니다.
- 이전 절차적 형상은 약 2mm 코드·6mm 비즈·18×7.6mm 잠금장치 목표를 참고했지만 실물에 근거하지 않는다. 현재 제품 화면에서 제외했다.
- 현재 화면은 카메라·손목 추적만 확인한다. 실물 기반 제품 모델을 확보한 뒤 착용 표시·보정·가림을 연결한다. 쇼핑·계정·결제·Android는 현재 구현 범위에 추가하지 않는다.

이슈의 본문과 댓글 이미지 두 개는 같은 MATERIAL WRAP 보드다. 재생용지·종이 띠·고정 카드·Material Record·소형 골판지 메일러의 포장 기준으로 보존했다. 파우치는 선택품이다. 제품 이미지의 촘촘한 배열과 중복 잠금장치를 3D 모델에 복사하지 않았다.

최우선 원본 `MEKIT 어스 브레이슬릿 디자인 보드.png`, 별도 제품/AR 원문 파일과 실제 3D 모델은 아직 없다. 최신 [실물 제품 기준](real-product-policy-2026-10-11.md)에 따라 임시 모델 검토와 제품용 3D 표시를 앱에서 제외했다. 이슈에 언급된 미승인 FIT STUDY 01도 확보한 것으로 기록하지 않는다.

## iPhone 출시까지의 연결

먼저 연결 가능한 실제 iPhone에서 [검증 시나리오](iphone-validation-2026-10-11.md)를 수행한다. 권한 허용·거절, 앱 전환, 추적 복구, 손목 이동·회전과 추적 복구를 실제 영상으로 확인하고 기기·OS·사용 가능한 자세를 기록한다. 현재 사용자는 iPhone을 연결할 수 없다고 알려 주었다. 시뮬레이터 결과를 이 단계의 완료로 처리하지 않는다.

실물 샘플·제품 원본·실물과 대조한 3D 자산을 확보한다. 제품용 모델을 연결한 뒤 부착·질감·가림을 실제 영상으로 확인하고 실물 길이/잠금장치를 검증한다. 그 뒤 완성 디자인 목록 → 제품 상세 → 착용 확인 → 후보 비교 → 길이 선택 → 주문/결제 흐름을 iPhone 앱에 연결한다. 기존 웹의 로컬 데모 주문을 실제 주문 서비스로 사용하지 않는다. 가격·주문·결제 결과를 확인하는 서버와 제작·배송 운영은 후속 출시 작업이다.

실기기 검증이 끝난 빌드를 TestFlight에 올릴 때에는 사용자의 Apple Developer Team, 최종 배포용 Bundle ID, App Store Connect 앱 레코드와 서명 설정이 필요하다. 현재 `com.casewingit.mekit.prototype`는 프로토타입 식별자이고 Team은 비어 있다. 업로드 전에 앱 레코드를 만드는 순서는 [Apple 안내](https://developer.apple.com/help/app-store-connect/create-an-app-record/add-a-new-app/)를 따른다. 계정 로그인·약관 동의·서명 계정 설정은 사용자가 수행한다.

TestFlight에서는 테스트 설명·연락처·서명된 빌드를 준비하고 내부 테스트부터 진행한다. 외부 테스터의 첫 빌드는 베타 심사가 필요할 수 있다. [Apple TestFlight 안내](https://developer.apple.com/help/app-store-connect/test-a-beta-version/testflight-overview/)를 참고한다. 현재 TestFlight 업로드·테스터 초대는 수행하지 않았다.

App Store 공개 전에는 실제 동작에 맞춘 앱 아이콘·스크린샷·소개·지원 URL·개인정보처리방침 URL과 앱 개인정보 응답을 완성한다. 현재 카메라는 기기 안에서 처리하고 프레임을 저장·전송하지 않는다. 후속 주문·분석 SDK 등이 들어오면 출시 버전의 데이터 처리 기준으로 응답을 갱신한다. iOS 앱의 개인정보처리방침 URL 및 개인정보 응답 요구는 [Apple 안내](https://developer.apple.com/help/app-store-connect/manage-app-information/manage-app-privacy/)를 따른다. 프로토타입 화면과 검증용 모델을 확정 실물 사진이나 정확한 피팅 기능으로 홍보하지 않는다.
