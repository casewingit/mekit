# 사진 참고 렌더링 스크립트

사용자 요청: Google에서 실제 제품 사진 한 장을 찾아 저장하고 반복 실행 가능한 렌더링 스크립트를 작성·실행한다. 이 대화에서 순차 구현한다.

사진: Google 이미지 검색에서 확인한 Sitti Olive Wood Bracelet - Lava Stone (Black) 판매 사진. EARTH 사진으로 표시하지 않는다. 원본 URL·해시·외부 제품 상태를 기록한다.

- [x] 색 기준의 윤곽 추출과 작은 구멍 보정, 원본 색 유지, 안쪽 큰 구멍 보존을 합성 테스트로 검증한다.
- [x] 사진 픽셀을 텍스처로 쓰는 높이 필드 메시를 만든다. 깊이는 추정임을 명시하며 뒷면은 복원하지 않는다.
- [x] PNG 정면/사선, 투명 텍스처, GLB, 독립 HTML 검토 화면과 결과 메타데이터를 출력한다.
- [x] `npm run render:reference`가 설치된 Python/Pillow/NumPy 또는 제공된 로컬 런타임에서 같은 입력으로 실행되게 한다. 재검색·외부 API 호출 없이 반복한다.
- [x] 실제 사진으로 실행하고 산출물과 재실행 결과를 확인한다. iPhone 제품 화면은 변경하지 않는다.
