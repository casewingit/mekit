# MEKIT 네이티브 앱 연결 구현

**Goal:** 기존 손목 추적 프로토타입을 컬렉션·길이 선택·실물 사진 스튜디오·로컬 보관이 연결된 iPhone 앱으로 만든다.

**Architecture:** SwiftUI 앱 셸과 EARTH 상세 화면, 로컬 사진 보관소, 후면 카메라 스튜디오를 분리한다. 기존 Vision 손목 추적에 사용자가 가져온 사진을 2D로 배치한다. 실물 샘플 및 정확한 3D 모델이 없는 상태에서 EARTH 착용 결과를 생성하지 않는다.

**Tech Stack:** iOS 17+, SwiftUI, AVFoundation, Vision, PhotosUI, ImageIO, Swift Package 테스트, XCTest.

## 기존 결정과 경계

- 웹·Pages는 수정하지 않는다. 첫 제품은 001 EARTH / 예정 가격 49,000원.
- 19.5 / 20.0 / 20.5cm는 미확정 비교 후보이며 선택은 기기에 저장한다.
- 크롬하츠 사진과 기존 절차적 메시를 MEKIT 상품 자산으로 번들에 넣지 않는다.
- 가져온 실물 사진은 별도 사진 스튜디오 자료이며 2D 참고 표시로만 사용한다. 배경 분리 전후를 사용자가 확인한다.
- 사진의 뒷면, 실제 둘레, 손목 뒤 가림, 촉감, 정확한 핏을 사진에서 추정하지 않는다.
- 계정·주문·결제는 최초 기술 검증의 제외 범위를 유지한다.
- iPhone 미연결·제품 자산 미확보·Apple 서명 계정 미설정은 출시 완료로 간주하지 않는다.

## 실행 순서

- [x] 좌표·보정·유효하지 않은 길이 복구 테스트를 먼저 추가하고 실패를 확인한다. 사진 배치 계산과 저장용 길이 정규화를 구현한다.
- [x] 컬렉션 / EARTH 상세 / 사진 스튜디오 / 보관함을 연결한다. 길이와 찜 상태를 AppStorage에 저장한다.
- [x] PhotosPicker·파일 선택·2048px 다운샘플·20MiB 제한·기기 내 Vision 배경 분리·검토·로컬 저장·삭제·오류 처리를 구현한다.
- [x] 카메라 화면에서 실제 사진만 추적 포즈에 배치하고 크기·가로·세로·각도 보정과 초기화를 연결한다. 추적 실패·중단·앱 이탈 시 사진을 숨긴다.
- [x] UI 테스트로 탐색, 길이 저장, 실물 자산 부재, 카메라 중지, 보관함과 개인정보 화면을 검증한다. iOS 단위 테스트로 이미지·보관소 오류/복원을 검증한다.
- [x] 시뮬레이터 스크린샷을 확인하고 unsigned iPhone 빌드를 실행한다. 실기기 미검증과 실제 3D 미구현을 문서에 기록한다.

## 추가 구현·검증

실물 USDZ 파일 가져오기·정규화·대조·로컬 보관·복원·취소·삭제와 SceneKit 카메라 합성·원통형 깊이 가림 근사를 연결했다. 테스트 안에서 만든 USDZ 형상을 실제 GPU로 렌더링해 앞/뒤의 픽셀 차이와 추적 상실 시 숨김을 확인했다. 실제 파일 브라우저와 취소는 UIKit 정상 모달로 연결했다. Core 16개, iOS 단위 10개, UI 7개 및 최종 unsigned iPhone 빌드를 확인했다. 실기기·EARTH 자산·서명·출시 검증은 구현 완료 범위에 포함하지 않았다.
