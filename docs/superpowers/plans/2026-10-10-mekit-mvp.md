# MEKIT MVP 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. 사용자가 코딩 시작을 승인했으므로 현재 대화에서 순서대로 실행한다.

**Goal:** 한국어로 네 가지 팔찌를 탐색하고 사이즈를 선택해 데모 주문을 생성·조회할 수 있는 앱을 만든다.

**Architecture:** React/TypeScript/Vite 브라우저 앱. 카탈로그·사이즈·데모 서비스와 화면을 분리하고 React Router로 직접 진입과 뒤로가기를 지원한다. 배송지 입력은 메모리에만 유지하며 로컬 저장소에는 비민감 데모 사양만 저장한다.

**Tech Stack:** React, TypeScript, Vite, React Router, Lucide, Vitest, Playwright.

## Global Constraints

- 고객 화면과 사용자 응답은 한국어.
- MEKIT 텍스트 워드마크만 사용.
- EARTH 39,000원, INDUSTRY 49,000원, AMBER 45,000원, FRAGMENT 47,000원은 제안 가격.
- 완성 길이 15–21cm, 0.5cm 단위. 딱 맞게 +0.5 / 편안하게 +1.0 / 여유 있게 +1.5cm.
- 범위 밖 추천은 임의 보정 없이 주문을 차단하고 상담으로 안내.
- 실제 결제·로그인·배송·문의 전송이 발생했다고 표시하지 않음.
- 구성 예시는 실물 사진·실제 크기가 아님. 완성 길이 오차 ±0.3cm는 제안 기준.
- 주소·전화번호·수령인 이름은 로컬 저장소에 저장하지 않음.
