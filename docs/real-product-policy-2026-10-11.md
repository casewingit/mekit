# MEKIT 실물 제품 기준

2026-10-11 사용자 요청: **“the product should be always real.”** MEKIT의 판매 대상과 제품 화면은 실제 팔찌를 기준으로 한다. 콘셉트 이미지나 임의로 만든 형상을 실물 제품처럼 표시하지 않는다. iPhone 앱의 착용 미리보기는 실제 판매할 제품의 외형·소재·배열을 재현해야 한다.

현재 저장소의 EARTH 절차적 메시와 GitHub 이슈의 콘셉트 보드는 실물 근거가 확인된 제품 자산이 아니다. “검증용”이라는 문구만으로 실제 EARTH 화면에 계속 표시하지 않는다. 제품용 3D 표시와 임시 모델 검토 진입을 앱에서 제외하고, 후면 카메라·손목 위치 추적 확인만 유지한다. 길이 세 개는 미확정 실물 비교 후보다. 선택이 실제 착용 모습이나 판매 가능 사이즈를 증명하지 않는다.

## 필요한 실물 근거

2026-10-11 사용자가 **아직 실물 EARTH 샘플이 없다고 확인했다.** 현재 단계는 제품 제작 전이며, 먼저 샘플 제작·검증이 필요하다. 제작 후 실제 샘플의 사진·치수·소재와 부품 배열을 확보한다. 현재 확보한 생성 콘셉트 보드를 실물 사진으로 바꾸어 표기하지 않는다.

3D 자산은 실물 촬영·스캔 또는 실물의 측정값과 사진에 맞춘 모델링으로 제작할 수 있다. 제작 방식 자체보다 실물과의 일치가 기준이다. 샘플 식별, 실제 소재·완성 길이·부품 치수·배열, 원본 사진과 텍스처의 출처, 승인한 모델 버전을 기록하고 실물 대조 후 제품 화면에 연결한다. 임시 메시의 플래그나 파일명을 바꾸는 것으로 실물 검증을 대신하지 않는다.

카메라 합성은 실물 기반 자산을 쓰더라도 실제 손목 둘레·조임·촉감이나 정확한 착용감을 보장하지 않는다. 표시되는 팔찌의 제품 정합성과 손목 추적·가림의 정확도는 별도로 검증한다. 영상은 기본 동작에서 저장하거나 전송하지 않는다.

## 코드와 참고 자료의 역할

`ios/MEKIT/BraceletMesh.swift`, `MetalBraceletView.swift`, `BraceletShaders.metal`은 이전 렌더러 기술 검증 코드로 보존한다. 현재 제품 화면에서는 호출하지 않는다. 해당 메시를 실물 제품으로 승인하지 않았다. 원래 시뮬레이터 GPU 검증 결과는 기술 검증의 과거 기록으로 남기며 실물 제품의 증거로 사용하지 않는다.

웹과 GitHub Pages는 이번 수정 범위에 포함하지 않는다. 기존 웹의 콘셉트 이미지는 출시 제품 사진으로 재사용하지 않는다. 실물 자료 확보 후 랜딩 페이지에도 승인된 제품 사진을 사용해야 한다.
