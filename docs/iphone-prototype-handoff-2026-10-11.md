# MEKIT iPhone 프로토타입 작업 기준

사용자가 2026-10-11 이 대화에 전달한 인수인계와 [GitHub 이슈 #2](https://github.com/casewingit/mekit/issues/2)를 기준으로 한다. 최신 요청에 따라 출시 플랫폼은 독립 iPhone 앱으로 확정했다. [출시 방향](iphone-release-direction-2026-10-11.md)을 참고한다. 기존 웹 소스와 GitHub Pages 게시 결과는 유지하고, 네이티브 작업은 `ios/`에 추가한다.

- 첫 제품: 001 EARTH, 소비자가 49,000원(VAT 포함). 완성 디자인과 길이를 선택한다. 기본 비교 길이 20.0cm, 19.5·20.0·20.5cm 후보는 미확정 실물 검토값이다.
- 반대편 손과 손목을 후면 카메라에 함께 비추는 세로 화면.
- SwiftUI, AVFoundation, Vision 손 포즈, 교체 가능한 Metal 렌더러.
- 첫 검증에는 쇼핑·결제·계정·다른 컬렉션·Android를 넣지 않는다.
- 손 랜드마크는 2D 위치·방향·화면상 크기의 근사값이다. 실제 손목 둘레·3D 형태·조임을 측정하지 않는다.
- 이슈 본문의 분산 비즈·슬림 올리브 코드·단일 실버 잠금장치 방향을 반영하며 세부 배열·비율은 실제 원본 확인 후 갱신한다. 이전 절차적 형상은 제품 복제가 아니다. 최신 [실물 제품 기준](real-product-policy-2026-10-11.md)에 따라 현재 화면에서 제외했다. 실물과 대조한 자산 확보 후 착용 표시·보정·가림을 연결한다.
- 기기 권한·추적 손실·앱 이탈에 팔찌를 숨긴다. 카메라 프레임·개인정보는 저장하거나 전송하지 않는다.
- UI/자동 검증과 실제 카메라·착용·가림 검증을 구분한다. 현재 앱은 카메라·손목 위치 확인을 제공하며 제품용 3D 모델 검토 진입은 없다.

## 확보한 자료와 아직 없는 자료

이슈 #2의 전체 본문과 댓글을 읽고 [원문 스냅샷](references/github-issue-2-2026-10-11.md)으로 보존했다. 두 이미지가 동일한 MATERIAL WRAP 보드임을 확인하고 `references/mekit-material-wrap-reference.png`로 확보했다. 제품·AR 기준은 이슈 본문에서 읽었으나 아래 별도 파일은 아직 복사되지 않았다. 파일을 읽었다고 기록하거나 내용을 임의로 복원하지 않는다.

- `references/mekit-handover-2026-10-11.txt`
- `finished-design-ar-direction-2026-10-11.md`
- `earth-development-2026-10-11.md`
- `MEKIT 어스 브레이슬릿 디자인 보드.png`

기존 웹 콘셉트 보드는 위 최신 원본의 대체 자료가 아니다. 웹의 이전 EARTH 가격·배열도 네이티브 제품 기준으로 복사하지 않는다.

사용자는 현재 실제 iPhone을 연결할 수 없다고 확인했다. 카메라·착용·가림 실기기 검증은 연결 가능한 시점에 수행한다. 현재 구현과 확인 결과는 `ios/README.md` 및 `docs/iphone-validation-2026-10-11.md`에 기록한다.
