# MEKIT iPhone 0.2.0 검증

기준: 2026-10-14 / Asia/Seoul. 웹과 Pages는 수정하지 않았다. 현재 iPhone 앱의 실행·범위는 [README](../ios/README.md)에 기록한다.

## 구현한 것

컬렉션·EARTH 상세·찜·길이 저장·실물 사진 스튜디오·USDZ 가져오기·보관함·개인정보 화면을 연결했다. 카메라의 손목 위치에 실제 가져온 사진 또는 모델만 표시한다. 외부 제품 사진과 절차적 EARTH 메시를 앱 자산에 포함하지 않았다.

사진은 2D 배치이며 기기 내 배경 분리 결과를 확인한 후 저장한다. 3D 모드는 가져온 USDZ를 사용하며 손목 뒤 가림은 측정하지 않은 원통 근사다. 2D 손 랜드마크로 정확한 깊이·손목 둘레·조임을 확보한다고 가정하지 않는다. 길이 선택이 모델의 실제 물리 치수를 변경하지 않는다.

## 확인 방법과 증거

- 환경: Xcode 27.0 / 27A266a, iPhone 18 Pro / iOS 27.0 및 별도 iPhone 17 Pro / iOS 26.5 시뮬레이터, 최소 배포 버전 iOS 17.
- Swift Core 16개: 좌표 변환, 손목 방향, 평활화, 오래된 프레임·추적 손실·250ms 만료, 보정 범위, 잘못된 저장 길이 복구, 사진 배치 좌표.
- iOS 단위 10개: 잘못된 이미지·20MiB 제한, 2048px 다운샘플, 투명 영역 크롭, 사진 저장·복원·삭제, 잘못된 기록 차단, 3D 형상 유효성·중심·스케일, 실제 USDZ 파일 가져오기·저장·복원·취소·삭제.
- 렌더러 테스트는 Metal 기반 SceneKit 스냅샷에서 앞쪽 빨간 테스트 형상은 유지되고 뒤쪽 파란 형상은 깊이 마스크로 가려지는 것을 픽셀로 비교한다. 추적 포즈가 없어지면 렌더 노드가 숨겨지는 것도 확인한다. 이 입력은 테스트 안에서 생성·삭제하는 박스 USDZ이며 팔찌 제품 모델이나 실기기 카메라 영상이 아니다.
- UI 7개: 컬렉션 → 상세, 길이 선택과 재실행 복원, 실물 자산 부재 안내, 보관함·개인정보, 시뮬레이터 카메라 제한과 중지, 사진·USDZ 파일 선택 및 취소. iOS 26.5 전체 17개 단위·UI 테스트가 통과했다. 최종 문서 브라우저 모달 연결 변경 후에는 실제 목록·취소·원래 화면 복귀 테스트를 별도로 재실행해 통과했다.
- unsigned `generic/platform=iOS` 빌드 성공. 설치·서명·App Store 업로드 성공을 의미하지 않는다.
- 앱 아이콘·개인정보 매니페스트가 빌드에 포함된다. `plutil` 검증과 `git diff --check` 통과.

## 검증 중 발견해 수정한 항목

보관함 안내 행의 빈 영역이 터치되지 않던 문제에 전체 행의 터치 영역을 적용했다. 3D 모델 중심 이동과 정규화는 중첩 노드로 분리해 축척 전후의 중심 오류를 수정했다. iOS 27의 SwiftUI 파일 선택기 취소 컨트롤은 접근성 기록에서 폭 1px의 Other로 표시됐다. 파일 브라우저가 실제 모달로 연결되는 UIDocumentPicker 프레젠터를 만들고, 취소 완료와 원래 화면 복귀를 검증한다. 스튜디오 하단 버튼은 안전 영역과 명시적인 스크롤 컨테이너로 가려짐을 피한다.

일부 실패 테스트 후 Xcode 27의 결과 수집이 끝나지 않아 해당 xcodebuild 프로세스만 종료했다. iOS 27 파일 선택기의 두 번째 취소 동작에서는 XCTest 러너가 접근성 확인 중 중단되어 전체 성공으로 처리하지 않는다. 앱 크래시 보고서는 없었지만 실기기와 해당 런타임에서 재확인이 필요하다. 별도 iOS 26.5 기기를 생성해 전체 테스트를 다시 실행하며 이전 실패를 성공으로 집계하지 않는다.

## 아직 확인할 수 없는 것

- 실제 iPhone의 카메라·권한 허용/거절·추적 품질·앱 이탈 복구·프레임 성능. 연결 가능한 실기기가 없고 기억된 iPhone은 unavailable이었다.
- EARTH 실물 샘플, 실물과 대조한 사진·치수·실제 3D 모델과 소재 질감.
- 실제 팔찌의 부착·회전·가림 자연스러움. 손목의 깊이·피부 형상을 측정한 가림은 구현하지 않았다.
- Vision 배경 분리가 실제 제품의 얇은 코드·작은 잠금장치·모든 비즈를 보존하는지 여부. 결과 확인과 원본 복귀를 제공하며 실물 사진 검증을 대신하지 않는다.
- iOS 17 실제 기기 실행, Apple 서명·TestFlight·App Store 심사·배포. 현재 Team은 빈 값이다.
- 초기 기술 검증 제외 범위인 주문·결제·계정·Android.

사용자 확인이나 USDZ 파일 유효성 검사만으로 실제 판매 제품의 인증이 이루어진다고 표시하지 않는다. 위 미검증 항목을 끝내기 전에는 구매용 EARTH AR 기능이나 출시 완료로 홍보할 수 없다.

## 다시 검증

`npm run ios:verify`는 XcodeGen → Core 테스트 → iOS 단위·UI 테스트 → unsigned iPhone 빌드를 실행한다. 기본 시뮬레이터는 iPhone 17 Pro / iOS 26.5이며 `MEKIT_SIMULATOR_NAME`과 `MEKIT_SIMULATOR_OS`로 변경할 수 있다. 테스트 결과 번들을 임시 폴더에 남긴다. 실행 가능한 Xcode와 해당 런타임이 설치되어 있어야 한다.
