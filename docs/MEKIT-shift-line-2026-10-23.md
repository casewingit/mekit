# MEKIT SHIFT LINE — 세 번째 라인

2026-10-23. 사용자가 승인한 방향: 2mm 먹색 로프, 작은 무광 블랙 금속, 짧은 코발트 실 감기, 드러난 매듭과 짧은 끝단의 스트리트 콘셉트. 코발트를 메인으로, 애시드 라임을 비교안으로 진행한다. 기존 INDIGO의 댄디함과 FIELD의 목재·원석 방향은 유지한다.

## 디자인

- INDIGO: 쪽빛, 셔츠와 데님, 단정한 매듭.
- FIELD: 흙빛, 캔버스 워크웨어, 목재와 작은 스모키 쿼츠.
- SHIFT: 먹색과 짧은 고채도 포인트, 워시드 블랙 데님, 콘크리트와 직접 플래시 사진.

공통은 가는 한 줄과 작은 디테일이다. SHIFT는 원석·목재·체인·큰 장식을 추가하지 않는다. 로프 외경 2mm, 금속 약9×4mm, 컬러 감기 길이 약5mm, 짧은 끝단은 시각 탐색 목표이며 확정 사양이 아니다. 생성된 두 이미지에는 형상 차이가 있으므로 정확히 동일한 부품의 색상만 바꾼 제품 사진으로 취급하지 않는다.

## 구조와 소재 확인

금속은 외형 목표만 무광 블랙이며 316L·티타늄·코팅 공법은 미확정이다. 코드가 Dyneema를 포함하는지, 컬러 감기가 폴리에스터인지 등은 공급 증빙으로 확인해야 한다. 감기는 장식의 역할이며 구조 강도를 보장하지 않는다. 짧은 끝단과 슬라이딩 매듭은 실제 손 통과·조절 범위·마찰·빠짐 방지를 함께 검토해야 한다. 컬러 실의 이염·보풀, 금속 접촉부의 코드 마모, 피부 접촉과 코팅 내구성도 샘플 검증 항목이다.
