# MEKIT RITUAL LINE — 2026-10-23

## 디자인 방향

사용자의 ‘묵주나 염주 같은 강한 원석·목재 팔찌’ 요청에 따른 네 번째 라인이다. INDIGO·FIELD·SHIFT의 가는 로프 중심 구성과 별도로, 구슬이 손목 전체를 감싸는 형태를 제안한다. 묵직함은 외관에 대한 표현이며 내구성 시험 결과가 아니다.

- 짙은 월넛 계열 목재: 전체의 약 ⅔, 광택을 낮춘 나뭇결.
- 스모키 쿼츠: 앞쪽 한 구간에 약 6–8개를 모으는 배열 후보.
- 구슬 지름: 약 6mm 목표. 생성 이미지의 구슬 수와 크기는 확정 도면이 아니다.
- 경계: 얇은 무광 블랙 스페이서 두 곳.
- 잠금: 뒤쪽 원통형 자석 잠금 후보. 자석 정렬과 이탈 방지 구조를 함께 검토한다.
- 분위기: 올리브 캔버스, 짙은 갈색, 거친 돌. 금색 장식과 다채로운 색상은 배제.

묵주·염주의 반복감에서 영감을 얻되 특정 종교의 구슬 수나 기도 용도를 재현한다고 표시하지 않는다. RITUAL은 작업용 라인명이다.

## 첫 샘플에서 결정할 것

1. 실제 수종과 마감 확인: 월넛이라는 이름은 현재 색·질감 방향이다. 공급자의 수종·코팅·이염·땀과 수분 반응을 확인한다.
2. 원석 확인: 스모키 쿼츠의 정체·처리와 가공 상태, 구멍 입구의 거친 면, 조립 후 충격 파손을 확인한다. 모스 경도 하나로 완제품의 튼튼함을 판단하지 않는다.
3. 내부 줄: 사용자가 원한 다이니마 소재를 후보로 두되 구슬 구멍, 줄 외경, 마찰, 끝단 고정의 호환성을 먼저 확인한다. 기존 로프 외경 2mm 목표를 이 라인 내부 줄에 그대로 확정하지 않는다.
4. 잠금: 목재·원석의 무게를 포함한 완제품에서 측면 당김·비틀림·반복 착탈·끝단 고정을 시험한다. 생성 이미지의 닫힌 원통은 작동 구조를 입증하지 않는다.
5. 착용: 구슬 지름과 손목 안쪽 여유를 반영해 사이즈별 실제 내주를 측정한다. 기존 로프형 완성 길이를 그대로 복제하지 않는다.

목재만 연결한 배열과 목재+원석 배열을 실제 손목에서 먼저 비교하고, 크기와 무게가 정해진 뒤 잠금 부품을 발주한다. 기존 INDIGO 출시 예산은 이 라인의 확정 원가가 아니다.
